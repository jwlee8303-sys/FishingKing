## 2. 운영 배포 없이 LAN 접속

PC와 휴대폰을 신뢰할 수 있는 같은 사설 Wi-Fi에 연결합니다. 공용 Wi-Fi·외부 인터넷 공개·터널·포트포워딩은 사용하지 않습니다.
PC에서 ipconfig로 해당 Wi-Fi의 사설 IPv4 주소를 확인하고 아래 예시 주소를 교체합니다.

```powershell
cd D:\FishingKing
$lanAddress = '192.168.1.23' # 자신의 사설 LAN 주소로 교체
npx.cmd --no-install vite --host $lanAddress --port 5174 --strictPort
```

휴대폰에서 `http://192.168.1.23:5174/game`처럼 자신의 PC 주소로 접속합니다.
이 명령은 선택한 LAN 주소에만 바인딩합니다. 이번 에이전트 실행에서는 LAN 서버를 실제로 열지 않았습니다.
바인딩 옵션은 [Vite server.host 공식 문서](https://vite.dev/config/server-options.html#server-host)를 따릅니다.
Windows 방화벽 승인이 필요하면 본인이 신뢰하는 사설 네트워크 범위만 확인합니다. 에이전트는 방화벽 규칙을 변경하지 않았습니다.
연결되지 않으면 주소·동일 서브넷·Wi-Fi의 단말 격리·PC 방화벽을 확인합니다. 무작정 전체 방화벽이나 TLS 검증을 끄지 않습니다.
검사가 끝나면 해당 터미널에서 Ctrl+C로 서버를 종료합니다. 기존127.0.0.1 개발 서버나 운영 서비스는 종료하지 않습니다.
LAN HTTP는 로컬 검사용이며 운영 HTTPS·실제 인증 보안 검증 결과가 아닙니다.
